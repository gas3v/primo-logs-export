# Публикация в Chrome Web Store

## Сборка пакета

```powershell
powershell -ExecutionPolicy Bypass -File scripts\pack.ps1
```

Скрипт:
1. Проверяет `manifest.json` (валидный JSON, есть `version`).
2. Проверяет, что все JS/JSON-файлы — валидный UTF-8 без BOM, без символов U+FFFE/U+FFFF
   и без невидимых символов U+200B…U+200D/U+FEFF внутри текста (их нужно писать escape-последовательностями).
3. Собирает `dist/primo-logs-export-<version>.zip`: `manifest.json` в корне, только файлы расширения,
   без `docs/`, `scripts/` и README. Этот архив загружается в магазин.
4. Собирает `dist/primo-logs-export-<version>-install.zip`: то же плюс `УСТАНОВКА.txt`. Этот архив
   раздаётся коллегам для установки в режиме разработчика.

Перед каждой загрузкой новой версии поднимите `version` в `manifest.json` и добавьте запись в `CHANGELOG.md`.

## Аккаунт разработчика

1. https://chrome.google.com/webstore/devconsole: войдите под **корпоративным или общим** аккаунтом
   компании, а не под личным.
2. Разовый регистрационный взнос **5 $**.
3. Включите двухэтапную аутентификацию: без неё публикация недоступна.
4. Подтвердите контактный email.

## Видимость

| Вариант | Кто видит | Когда |
|---|---|---|
| Public | Все, есть в поиске | Публичный инструмент для клиентов |
| Unlisted | Только по ссылке | Раздача клиентам и поддержке по ссылке (рекомендуется для начала) |
| Private | Только домен Google Workspace или список тестировщиков | Внутренний инструмент |

## Карточка (Store listing)

- **Название:** Primo: выгрузка логов робота в Excel
- **Краткое описание** (до 132 символов): «Выгружает события операции робота из Primo Orchestrator в Excel (.xlsx) или CSV с учётом фильтров страницы.»
- **Категория:** Developer Tools или Productivity.
- **Язык:** русский.
- **Иконка:** `icons/128.png`.
- **Скриншоты:** минимум 1, 1280×800 или 640×400 (страница событий с плашкой прогресса, открытый Excel-файл).
- **Малый промо-баннер:** 440×280 (обязателен для Public).

## Privacy practices

- **Single purpose:** выгрузка событий операции робота из Primo Orchestrator в файл Excel или CSV.
- **Обоснование разрешений:**
  - `activeTab`: доступ к открытой вкладке оркестратора, только когда пользователь кликает на иконку.
  - `scripting`: внедрение скрипта выгрузки в эту вкладку по клику.
  - `downloads`: сохранение сформированного файла Excel или CSV. Скачивание со страницы Chrome блокирует
    при повторных выгрузках без перезагрузки страницы.
  - `contextMenus`: пункты «Выгрузить в Excel» и «Выгрузить в CSV» в меню иконки расширения.
- **Remote code:** No. Весь код находится в пакете, сторонние библиотеки не загружаются.
- **Data usage:** расширение читает токен сессии оркестратора и события робота, но обращается только
  к API того же оркестратора, открытого во вкладке. Файл формируется локально, данные никуда не отправляются,
  не собираются, не продаются и не передаются третьим лицам.
- **Privacy policy URL:** нужна публичная страница с той же формулировкой (сайт компании или GitHub Pages).

## Отправка

1. **Add new item** → загрузите ZIP из `dist/`.
2. Заполните Store listing, Privacy и Distribution (видимость, регионы).
3. **Submit for review**. Проверка занимает от нескольких часов до нескольких дней.
4. Обновления: поднимите `version`, соберите ZIP, загрузите в **Package → Upload new package**.

## Корпоративная раздача без ручной установки

Администратор может принудительно установить расширение через групповые политики Chrome
(`ExtensionInstallForcelist`) по ID из магазина. Подойдёт и вариант Unlisted или Private.
