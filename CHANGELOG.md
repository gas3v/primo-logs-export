# Changelog

## Не выпущено

- Тесты генераторов xlsx и csv (`npm test`), CI на GitHub Actions: проверки, тесты, сборка архивов,
  релиз по тегу `v*`.
- README переработан: возможности, установка из Releases, схема работы.
- Код расширения не менялся.

## 1.1.1 — 2026-11-11

- Описание и подсказка иконки в манифесте упоминают CSV и меню по правому клику.
- Невидимые символы в `exporter.js` и `csv-writer.js` записаны escape-последовательностями
  (поведение не изменилось); `scripts/pack.ps1` теперь не пропускает невидимые символы
  U+200B…U+200D/U+FEFF в JS.
- Документация актуализирована: адреса страниц, скорость API, глобальные переменные, порядок ручной проверки.

## 1.1.0 — 2026-11-11

- Выгрузка в CSV: правый клик по иконке → «Выгрузить в CSV». Левый клик по-прежнему выгружает Excel.
  Формат для Excel с русской локалью: разделитель `;`, UTF-8 с BOM, CRLF.
- Добавлено разрешение `contextMenus` (меню иконки, предупреждения при установке нет).

## 1.0.1 — 2026-11-11

- Исправлено: повторная выгрузка без перезагрузки страницы (F5) не скачивала файл. Chrome блокировал
  второе автоматическое скачивание со страницы («Сайт пытается скачать несколько файлов»). Теперь файл
  сохраняется через `chrome.downloads`, добавлено разрешение `downloads`.
- Если автоматически сохранить файл не удалось, на плашке появляется кнопка «Скачать файл».
- После завершения на плашке есть кнопка «Скачать ещё раз».
- В прогрессе показывается примерное оставшееся время.
- Скрипт выгрузки работает в изолированном мире контент-скрипта, а не в контексте страницы.

## 1.0.0 — 2026-11-10

- Первая версия: выгрузка всех событий операции робота в `.xlsx` по клику на иконку.
- Учитываются фильтры страницы: период, EntityId, ElementName/Id/Class, сообщение, «со снимком экрана».
- Названия событий берутся из справочника `OperationEventTypes`.
- Собственный генератор xlsx без зависимостей: закреплённый заголовок, автофильтр, даты с миллисекундами.
- Ошибка внедрения скрипта показывается значком `ERR` и текстом в подсказке у иконки.
- Исправлено: символы U+FFFE/U+FFFF были записаны в `xlsx-writer.js` буквально, и Chrome отказывался
  загружать файл («isn't UTF-8 encoded»).
